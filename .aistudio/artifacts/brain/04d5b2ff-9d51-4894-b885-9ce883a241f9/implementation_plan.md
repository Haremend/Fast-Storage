# UpCloud Vault — iOS 风格单用户认证与全栈智能架构升级计划

本升级方案将为 UpCloud Vault 引入基于环境变量配置的单一管理员安全登录认证系统、全面重构为现代 iOS 明亮磨砂玻璃（Frosted Glassmorphism）视觉设计语言、完善个人文档真实下载与公开 CDN 直链分发、打造语义检索与 QStash 异步队列的深度教学演示用例，并构建全功能 Redis 键值浏览器与经典特性实验舱。

---

### User Review & Critical Decisions

> [!IMPORTANT]
> 基于第一阶段的澄清反馈，已锁定以下关键技术决策与产品范式：

- **确认决定 1（单用户环境变量认证）**：单一用户凭证由 Vercel / 生产环境变量 `ADMIN_USERNAME` 与 `ADMIN_PASSWORD` 控制（提供开箱即用的默认值供本地与演示环境预览）。登录成功后签发安全的 HTTP-only Cookie，并在 Upstash Redis 中注册当前活跃会话与心跳记录，未授权用户无法访问核心管理面板。
- **确认决定 2（iOS 现代毛玻璃美学体系）**：深度应用苹果设计规范（Apple HIG & iOS Design Language），采用明亮通透的半透明磨砂毛玻璃层级（`backdrop-blur-xl bg-white/70 dark:bg-slate-900/75 border border-white/40 dark:border-white/10`）、精致平滑的 iOS 卡片圆角（`rounded-2xl`）、扁平化层级以及原生浅色/深色模式无缝切换。
- **确认决定 3（文档直链与真实下载）**：文件上传至 Upstash Blob 后，支持查看详细文件体积与 MIME 类型，提供真实的二进制文件直接下载（`Content-Disposition: attachment`），以及一键生成并复制全球 CDN 公开直链。
- **确认决定 4（直观教学演示用例舱）**：
  - **语义检索对比舱**：直观对比“传统字面关键词匹配”与“Upstash Vector 稠密语义理解”，让非技术用户一目了然语义搜索的本质价值。
  - **QStash 异步队列削峰舱**：模拟高并发批量任务提交，前台毫秒级释放，后台队列自动执行状态流转。
  - **Redis 键值空间浏览器与经典用例**：支持查看 Redis 实例内存信息与所有活跃 Key，支持查看、编辑、新增、删除及修改 TTL；配套提供 API 频控限制器（Rate Limiter）与分布式原子计数器（Atomic Counter）交互演示。

### 1. 核心架构与功能重构规划

#### 1.1 模块结构与导航重构
整体重构为 6 大一级功能板块，侧边栏与顶栏同步采用 iOS 风格：
1. **工作台概览 (Overview)**：核心资产概况、存储用量、服务连通性总览与快速导航。
2. **个人云端文档 (Documents)**：完整的文件上传、分类筛选、元数据查看、真实下载与公开 CDN 直链复制。
3. **语义检索体验舱 (Semantic Intelligence)**：不仅包含自然语言检索，还新增“传统硬匹配 vs 向量语义匹配”实时对比实验舱与关联推荐演示。
4. **QStash 队列演示舱 (Task Queue & Pipeline)**：任务流转追踪、单任务重试，以及“模拟高并发批量入库压测”交互式演示工具。
5. **Redis 空间与经典用例 (Redis Studio)**：
   - *Redis 实例环境信息与键值浏览器*：搜索键名、查看类型、修改内容、设定 TTL、快速删除与新增。
   - *经典特性实验舱*：分布式 API 频控保护（Rate Limiting）演示、毫秒级分布式原子访问计数器（Atomic Counter）。
6. **架构与云端连接 (Architecture & Status)**：Upstash 4 大原语连接状态诊断、实时延迟遥测、缓存清空与 Vercel 环境变量说明。

### 2. 界面与交互设计（iOS Frosted Glassmorphism）

#### 2.1 视觉风格与色彩体系
- **材质质感**：明亮背景配合高饱和柔和弥散光斑，前置容器使用 `backdrop-blur-2xl bg-white/70 dark:bg-slate-900/75 border border-white/50 dark:border-white/10`，呈现纯正的 iOS 磨砂玻璃质感。
- **色彩规范**：
  - 主色（iOS Emerald & Azure）：高纯度薄荷绿 (`#10B981`) 与苹果天蓝 (`#0A84FF`)，用于核心交互按钮与激活态。
  - 衬底色：浅色模式采用苹果经典的冷白微灰基底 (`#F5F5F7`)，深色模式采用深空灰与曜石黑 (`#0B0F19`)。
- **排版与间距**：大字体标题、清晰的视觉层级、数据与计数器一律采用等宽数字 (`font-mono tabular-nums`)，避免跳动。
- **无障碍与交互微动效**：轻微的弹性点击响应、平滑的折叠展开、状态切换微动画与清晰明了的轻量 Toast 通知。

#### 3.1 认证与会话管理 (`/api/auth/login`, `/api/auth/me`, `/api/auth/logout`)
- 环境变量读取：`ADMIN_USERNAME` (默认 `admin`)，`ADMIN_PASSWORD` (默认 `admin123456`)。
- 登录流程：用户提交凭证 $\rightarrow$ 服务端比对 $\rightarrow$ 生成安全 Session 令牌存入 Redis（7天有效期）并下发 HttpOnly Cookie `auth_session`。
- 权限保护：在敏感 API（文档上传/删除、Redis 修改键、队列触发）加入会话校验拦截，未登录时前端平滑呈现 iOS 风格全屏磨砂登录卡片。

#### 3.2 个人文档管理增强 (`/api/documents/download`)
- 真实二进制文件下载：新增 `/api/documents/download?id=xxx` 接口，输出流式二进制内容并设置 `Content-Disposition: attachment; filename="..."`，支持浏览器直接下载真实文件。
- 公共直链（Public Download Link）：自动组装 Upstash Blob 全球 CDN 永久直链或服务器公开直链，提供一键复制与复制成功反馈。

#### 3.3 语义检索对比舱 (`SemanticSearchView`)
- 引入交互式对比试验：用户输入一个自然语言问题（如“如何让网页加载更快并解决并发瓶颈”），界面左侧展示**传统字面搜索**结果（由于缺少字面关键词直接命中为0），右侧展示 **Upstash Vector 语义检索**结果（基于概念理解，匹配出“CDN 缓存加速”、“QStash 异步削峰”等文档并计算余弦相似度百分比），让价值直击人心。

#### 3.4 QStash 异步队列演示舱 (`TaskQueueView`)
- 提供“单任务手动触发”与“高并发批量并发压测演示（一键发射 5 个任务）”两种体验。
- 界面通过可视化的工作流阶段（排队中 $\rightarrow$ 正在处理 $\rightarrow$ 自动重试 $\rightarrow$ 成功完成）展示 QStash 的解耦和削峰能力。

#### 3.5 Redis 空间管理器与经典用例 (`RedisStudioView`)
- **Key-Value 空间管理器**：调用 Redis 命令检索键名、类型（string、hash 等）、TTL 倒计时与值内容；支持在线编辑值、更新 TTL、手动创建新键与一键删除键。
- **经典用例 1 - API 滑动窗口频控器**：用户快速点击“请求接口”，界面实时显示 Redis 令牌桶计数，当超过阈值（如 5次/10秒）时触发 429 限流并展示 Redis TTL 剩余锁定时长。
- **经典用例 2 - 全局原子访问计数器**：演示 Redis `INCR` 原子递增，多终端并发请求零冲突。
